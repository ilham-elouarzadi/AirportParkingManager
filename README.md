# AirportParkingManager

Application de bureau moderne développée en **JavaFX** pour la gestion automatisée d'un parking aéroportuaire. 

## Fonctionnalités
* **Gestion des Véhicules** : Enregistrement des entrées et sorties en temps réel.
* **Système d'Abonnement** : Gestion des différents types d'abonnés (mensuel, annuel, etc.).
* **Suivi des Stationnements** : Visualisation des places occupées et calcul automatique des tarifs.
* **Interface Intuitive** : Design fluide réalisé avec JavaFX et FXML.

## Technologies utilisées
* **Langage** : Java 17+
* **Interface Graphique** : JavaFX
* **Gestion de projet** : Maven
* **Architecture** : MVC (Modèle-Vue-Contrôleur)
